<h2 id="español">🇪🇸 Español</h2>

Una página de enlaces personalizada (tipo Linktree) construida exclusivamente con **HTML5 y CSS3**. Diseñada con un enfoque minimalista, moderno y elegante.

### 🌟 Características Principales
- **Dark Mode & Glassmorphism**: Diseño oscuro con botones translúcidos, bordes sutiles y desenfoque de fondo (`backdrop-filter`).
- **Puro HTML/CSS**: Sin frameworks pesados. Código limpio, semántico y ultraligero.
- **100% Responsive**: Se adapta a la perfección tanto a pantallas de móviles como de escritorio gracias a Flexbox.
- **Animaciones Suaves**: Efectos de escalado al tacto, brillos deslizantes ("Glow Sweep") y un pulso constante para el enlace destacado.
- **Gráficos SVG Integrados**: Logos vectoriales directamente en el código para una nitidez absoluta y carga instantánea, utilizando los colores corporativos oficiales.

### 🚀 Cómo usarlo
Al ser un proyecto *Vanilla* (puro HTML/CSS), no requiere de instalaciones, dependencias ni servidores.
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` directamente en tu navegador web.
3. ¡Listo! Puedes alojarlo gratuitamente en plataformas como Vercel, Netlify o GitHub Pages.

<h2 id="english">🇬🇧 English</h2>

A custom link page (Linktree alternative) built entirely with **HTML5 and CSS3**. Designed with a minimalist, modern, and elegant approach.

### 🌟 Key Features
- **Dark Mode & Glassmorphism**: Deep dark background with translucent buttons, subtle borders, and background blur (`backdrop-filter`).
- **Pure HTML/CSS**: No heavy frameworks. Clean, semantic, and ultra-lightweight codebase.
- **100% Responsive**: Flawlessly adapts to both mobile and desktop screens using Flexbox.
- **Smooth Animations**: Touch-friendly scaling effects, sliding highlights ("Glow Sweep"), and a continuous pulse animation for the featured link.
- **Inline SVG Graphics**: Vector logos embedded directly into the code for infinite scalability and instant loading, styled with official brand colors.

### 🚀 How to use
Since this is a *Vanilla* project (pure HTML/CSS), it requires no installation, dependencies, or local servers.
1. Download or clone this repository.
2. Open the `index.html` file directly in your web browser.
3. You're good to go! You can easily host it for free on platforms like Vercel, Netlify, or GitHub Pages.
